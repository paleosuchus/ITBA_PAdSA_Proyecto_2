================================================================================
CODE STRUCTURE SUMMARY: implementation/ (Project 2 — RLS Adaptive Filtering)
================================================================================

Overview:
---------
A clean, modular implementation of the 5-dimensional Dual-PPG + 3-Axis
Accelerometer Heart Signal Reconstruction and RLS Hyperparameter Optimization
Pipeline for Project 2. Preprocessing and BPM detection are kept strictly minimal
so that the MISO adaptive filter is the core motion-cancellation mechanism.
The RLS algorithm is implemented with all hyperparameters tunable (`M`, `lam`,
`delta`, `w_init`), while NLMS and VS-LMS are implemented with the optimal
hyperparameters already obtained in Project 1 for direct side-by-side comparison.

Module Breakdown:
-----------------
1. dataset_preparation.py
   - `load_ts(path)`: Loads 5D windows `(n_windows, 5, 1000)` and BPM labels `y`.
   - `split_participants(X)` & `get_participant_groups(X)`: Detects recording
     session / participant boundaries via 750-sample overlap matching without
     merging windows.
   - `subject_wise_group_kfold(X, n_splits=5)`: Partitions windows strictly by
     subject ID using `sklearn.model_selection.GroupKFold` to prevent data leakage.

2. preprocessing.py
   - `bandpass(x, lo=0.5, hi=4.0, fs=125, order=4, causal=False)`: 4th-order
     zero-phase Butterworth bandpass filter in the cardiac band (30 - 240 BPM).
   - `normalize_amplitude(x)`: Zero-mean, unit-variance normalization per channel.
   - `preprocess_signal(x)`: Minimal preprocessing returning `(ppg1, ppg2, acc)`
     where `acc` has shape `(3, N)` (`[accx, accy, accz]`).

3. reference_construction.py
   - `build_U(acc, M)`: Constructs the `(N, 3 * M)` MISO tapped-delay regressor
     matrix for $\hat{m}[n] = \sum_{k=1}^3 \mathbf{w}_k^T[n]\mathbf{a}_k[n]$.

4. LMS_algorithms.py
   - `rls(d, acc, M=12, lam=0.99, delta=1.0, lambda_=None, w_init=None)`:
     Recursive Least Squares (RLS) MISO adaptive filter with all hyperparameters
     tunable (`M`, forgetting factor `lam`, inverse correlation initialization
     `delta` where $\mathbf{P}[0] = \delta^{-1}\mathbf{I}_{3M}$, and `w_init`).
   - `nlms(d, acc, M=22, mu=0.01288, delta=0.5, w_init=None)`:
     Normalized MISO LMS configured with its optimal Project 1 hyperparameters.
   - `vs_lms(d, acc, M=18, mu_max=0.06558, mu_min=0.00791, alpha=0.98503, gamma=0.00053, delta=1.0, w_init=None)`:
     Kwong-Johnston Variable Step-Size MISO LMS configured with its optimal
     Project 1 hyperparameters.
   - `lms_bucket(ppg1, ppg2, acc, algorithm='rls', M=None, **hyperparams)`:
     Runs the selected adaptive filter (`rls`, `nlms`, or `vs_lms`) in parallel on
     `ppg1` and `ppg2` and fuses `e1` and `e2` via `snr_weighted_late_fusion`.

5. fusion.py
   - `estimate_cardiac_snr(sig)`: In-band cardiac spectral SNR in `[0.5, 4.0] Hz`.
   - `compute_snr_weights(e1, e2)` & `snr_weighted_late_fusion(e1, e2)`: Combines
     parallel-filtered PPG channels using SNR weights $w_i = \text{SNR}_i / (\text{SNR}_1 + \text{SNR}_2)$.

6. bpm_detection.py
   - `zero_padded_periodogram_bpm(x, fs=125, nfft=8192, lo=0.5, hi=4.0, window_type='hann')`:
     Direct zero-padded periodogram peak detector in `[0.5, 4.0] Hz`.
   - `elgendi_systolic_peak_bpm(x, fs=125, w1_sec, w2_sec, beta_offset)`:
     Time-domain systolic peak heart rate detector.
   - `estimate_bpm_window(e_window, hr_algorithm, **hr_params)`: HR bucket function.
   - `objective_function(bpm_estimated, bpm_true)`: Outlier-penalized error metric.

7. pipeline.py
   - `reconstruct_heart_signal(window_5d, ...)`: End-to-end window signal cleaning.
   - `predict_window_bpm(window_5d, ...)`: End-to-end single-window BPM prediction.
   - `HeartRateEstimatorModel`: Encapsulates a configured Adaptive Filter + HR
     pipeline with `.predict(X)`, `.predict_with_signals(X)`, and
     `.from_project1_optimal(algorithm)`.

8. optimization.py
   - `optimize_hr_pipeline(X, y, n_splits=5, ...)`: Optimizes ONLY the `rls`
     hyperparameters (`M`, `lam`, `delta`) and selects the best HR detection model
     (`periodogram` vs `elgendi`) using Subject-Wise Group K-Fold CV and 2-phase
     Conditional TPE optimization with `MedianFoldPruner`. Returns the optimized
     `rls` model alongside the pre-configured Project 1 optimal `nlms` and `vs_lms`
     models and the unfiltered baseline (`Before Filtering`).

9. pipeline_optimization_and_evaluation.ipynb
   - Presents the Project 2 RLS pipeline, optimizes RLS + HR detector via 5-fold
     Subject-Wise Group K-Fold CV, compares CV and Test Set performance of RLS
     against the Project 1 optimal NLMS and VS-LMS models and the unfiltered
     baseline, plots the spread of Test BPMs for RLS colored by subject, visualizes
     a single window transforming across each step of the RLS pipeline, compares a
     good RLS example against an RLS outlier example, and finally runs RLS on the
     exact same outlier window (#481) analyzed in Project 1.
